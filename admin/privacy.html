Privacy Policy

This application, “Saltcoats Victoria Auto Poster”, is operated by Saltcoats Victoria F.C. and managed by Colin Lundy.

The app is used only to publish automated updates from club systems (such as league tables or match results) to the official Saltcoats Victoria Facebook Page.

We do not collect, store, or share any personal data from users. All actions are performed via Facebook’s secure API using access tokens associated with the official page administrators.

If you have any questions about this policy, you can contact the administrator at colin@lundy.me.uk.
